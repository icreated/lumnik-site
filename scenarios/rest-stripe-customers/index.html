L'API de Stripe: on la nomme, starting_after fait le reste.

Objectif Lire tous les clients d'un compte Stripe, page après page, sans écrire la pagination.

Stripe pagine par curseur: chaque page dit has_more, la suivante se demande avec starting_after, l'id du dernier client lu. lumnik a un preset du même nom:

  • pagination: { kind: stripe }: 25 clients en 3 requêtes;
  • le lendemain, 5 nouveaux clients: 30 lignes, une par client.

L'API de Stripe, 25 clients

localstripe 1.15, un faux Stripe libre et avec état, utilisé dans les suites de tests, sert l'API de Stripe. 25 clients créés par l'API.

  • object: list
  • has_more: il reste des pages
  • data: 10 clients par page
  • la page suivante: starting_after=<id du dernier client>
  1. 1
    Pourquoi localstripe

    stripe-mock, le serveur de test officiel, est sans état: sa liste rend toujours le même client et ne pagine pas.

Une ligne: pagination: { kind: stripe }

Un connecteur rest-generic.

  • auth: bearer: la clé secrète du compte, rangée par lm secret
  • pagination: stripe: starting_after sur le dernier id, jusqu'à has_more false
  • created: transform from_epoch, la date de Stripe est en secondes
  1. 1
    3 requêtes

    limit=10, puis starting_after deux fois.

Les clients sont dans Stripe.

Il faut les lire tous, chaque nuit.

API Stripe servie par localstripe, en test

Le problème

Stripe rend ses clients par pages de 10.

  • Chaque page dit s'il en reste.
  • La suivante se demande à partir du dernier client lu.

Ce qui n'est pas modifié

Le compte reste tel quel.

  • Une clé de test, rangée par lm secret.
  • L'API standard de Stripe.

Ce qu'il a fallu écrire

pagination: { kind: stripe }

On nomme l'API.

Un connecteur de 24 lignes.

Le résultat

25 clients, 3 pages.

  • Chaque client sous son id Stripe.
  • La date de création convertie depuis l'epoch.

Le lendemain

5 nouveaux clients: 30 lignes.

  • Une ligne par client, sans doublon.
  • La nuit relit tout le compte.

La limite

Rejoué sur localstripe, pas sur Stripe.

  • Un faux Stripe libre, utilisé en tests, avec état.
  • Le vrai Stripe se lit pareil, avec la clé du compte.
