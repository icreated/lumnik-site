Le dépôt SFTP du transporteur : chaque nuit lue, rangée, et rien sur parole.

Un transporteur dépose chaque nuit livraisons.csv sur son serveur SFTP, toujours sous le même nom. lumnik relit une nuit de même taille, range chaque nuit sous son propre nom, dit sur le run un fichier qu'il n'a pas pu archiver, et refuse un serveur dont la clé a changé.

Le serveur du transporteur, sa clé vérifiée

Un connecteur CSV sur le SFTP du transporteur. L'empreinte de sa clé est relevée hors bande puis épinglée ; le mot de passe est un secret du hub, jamais dans le manifeste.

  1. 1
    Confiance

    Le hub ne parle qu'au serveur dont il connaît la clé.

  2. 2
    Archivage

    after_process: archive vide le dossier de dépôt.

Relu, archivé à côté de la nuit 1

Le transporteur réécrit livraisons.csv avec d'autres statuts et le même nombre d'octets. Le fichier est relu et rangé sous son propre nom : la nuit 1 reste dans l'archive.

  2. 2
    Deux archives

  2. 2
    Rien de perdu

    Les lignes sont dans le hub.

Refusé, les deux empreintes nommées

Le transporteur réinstalle son serveur : sa clé change. Le run échoue avant toute lecture et nomme l'empreinte présentée et celle déclarée.

  1. 1
    Refus

    Une autre clé, c'est peut-être un autre serveur.

  2. 2
    Le geste

    Confirmer l'empreinte avec le transporteur, puis l'épingler.

La nuit suivante lue, puis archivée

L'empreinte confirmée est épinglée. La nuit 4, déposée sous le même nom que la nuit 3 jamais archivée, est lue puis archivée : elle n'est pas rangée sans avoir été lue.

  1. 1
    Lue d'abord

    Seule la version lue est archivée.

  2. 2
    Archive

    livraisons.<heure>.csv pour la nuit 4.

Ce que prouve cette étape

Un fichier n'est jamais archivé sans avoir été lu.

Limites

  • La vérification avant le déplacement n'est pas atomique : un fichier déposé dans les millisecondes entre les deux est encore déplacé.
  • Un transporteur qui écrit sous un autre nom puis renomme n'est jamais pris dans cet intervalle.
  • Serveur SFTP simulé ; données synthétiques.
