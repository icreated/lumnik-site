Le guichet SOAP du CRM lu service par service sans rien lire deux fois

Objectif Lire les services SOAP d'un vieux CRM, chacun comme il se lit, sans le marteler.

Un CRM des années 2000 expose ses données par des services SOAP sur mesure. Le mot de passe voyage dans l'enveloppe.

  • un service lu en un appel, un autre page par page;
  • le Fault du CRM sur le run, sans nouvel essai;
  • la nuit suivante mise à jour sur les clés.

L'enveloppe telle qu'elle part, le mot de passe en secret

Deux connecteurs REST au format SOAP sur le même guichet. Le mot de passe est un secret du hub. Le pré-vol envoie la vraie requête.

  • les deux services répondent
  1. 1
    SOAPAction

    Chaque service est nommé comme le CRM l'expose.

  2. 2
    {{page}}

    Le numéro de page, à partir de 1.

Limites

  • Une lecture SOAP se fait en une passe, en mémoire: lm run cancel n'agit qu'à la fin de la lecture.
  • Le service est appelé pour une demande et un client écrits dans le manifeste ; un appel par demande d'une liste n'est pas couvert.
  • La marque d'un import incrémental voyage dans l'URL, pas dans le corps: un service qui filtre par période dans le corps est relu en entier.
  • CRM simulé ; données synthétiques.

CRM · SOAP

Le CRM parle SOAP.

Des services sur mesure, des années 2000.

CRM simulé, deux services

Le problème

Chaque service se lit à sa façon.

  • Un service rend tout en un appel.
  • Un autre pagine par numéro de page.

Ce qui n'est pas modifié

Le CRM reste tel quel.

  • Ses services, son enveloppe.
  • Un compte de service.

Le piège

Marteler le CRM.

  • Relire la même page en boucle.
  • Réessayer un mot de passe refusé.

Ce qu'il a fallu écrire

<data:page>{{page}}</data:page>

Une ligne.

  • Le numéro de page, là où le service l'attend.
  • L'arrêt sur la dernière page.
  • Deux manifestes, 84 lignes.

Un refus

Le Fault du CRM, tel quel.

  • Sur le run, avec son code.
  • Une seule tentative.

La limite

Une demande, un client, écrits dans le manifeste.

  • Un appel par élément d'une liste n'est pas couvert.
