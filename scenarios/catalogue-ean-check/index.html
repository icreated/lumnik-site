Le code-barres faux repéré à l'import

Un export catalogue porte des codes EAN-13, dont certains faux. Aucun transformateur intégré ne calcule la clé de contrôle.

  • l'opérateur du hub dépose un script Kotlin
  • le manifeste le nomme, sans transporter de code
  • un brouillon qui ne compile pas est refusé à la validation
  • chaque code reçoit un verdict à l'import.

L'opérateur dépose, l'intégrateur voit

Deux scripts dans le répertoire de scripts du hub, monté en lecture seule.

  • ean-draft.kts: brouillon cassé exprès, ligne 8, pour montrer le refus
  • ean-check.kts: le contrôle terminé
  • lm hook scripts les liste, avec taille et empreinte SHA-256

Un script qui ne compile pas est refusé

Le manifeste nomme d'abord le brouillon.

  • script: hooks:<nom>.kts: le connecteur nomme le script, il ne le contient pas
  • lm validate le compile et le refuse: ligne 8, colonne 20
  • Aucun connecteur n'est créé
  1. 1
    8:20

    Une liste à la place d'un nombre, ligne 8, colonne 20.

  2. 2
    Pourquoi nommer

    Un script a tous les droits du hub: seul l'opérateur l'installe, le manifeste ne fait que le choisir.

Limites

  • Un script tourne avec tous les droits du hub: seul l'opérateur en installe un.
  • Un script remplacé s'applique au lot suivant, pas au milieu d'un lot.
  • Le script tourne sur les imports CSV.
  • Catalogue synthétique, codes au préfixe 200, réservé à l'usage interne.

L'export catalogue porte 10 codes EAN-13. Trois sont faux.

Catalogue fictif · données synthétiques

Le problème

Le dernier chiffre se calcule.

  • Un EAN-13 finit par une clé de contrôle.
  • Une faute de saisie la rend fausse.
  • Aucun outil standard ne la vérifie à l'import.

La règle

L'opérateur dépose un script. Le manifeste le nomme.

mapping:
  cell:
    - kotlin:
        script: hooks:ean-check.kts

2 manifestes, 24 lignes. Un script de 10 lignes.

Avant tout import

Un script faux est refusé à la validation.

  • Ligne 8, colonne 20.
  • Aucun connecteur créé.
  • Rien n'est importé.

Le résultat

Chaque code reçoit un verdict.

  • 7 codes valides.
  • 2 clés de contrôle fausses: ART-104, ART-108.
  • 1 code de 12 chiffres: ART-110.

Valeurs réelles, rejeu du 28 octobre 2026.

La sécurité

Le script a tous les droits du hub.

  • Seul l'opérateur l'installe.
  • L'intégrateur le choisit par son nom.
  • L'empreinte SHA-256 dit quelle version tourne.
