Quatre demi-journées non justifiées dans le mois: l'établissement doit agir

Objectif Savoir, dès l'export mensuel, quels élèves atteignent quatre demi-journées d'absence non justifiées, et lesquels dépassent dix, sans ouvrir le rapport du logiciel.

Dès quatre demi-journées non justifiées dans le mois, le chef d'établissement convoque la famille. Au-delà de dix, le Dasen est informé. Le logiciel de vie scolaire compte, mais le compte reste dans un rapport.

  • l'export mensuel arrive par SFTP
  • deux Process, un par seuil
  • une décision par élève et par seuil franchi

L'export d'octobre, puis deux seuils

Le logiciel de vie scolaire dépose son export mensuel sur un serveur SFTP. Octobre arrive d'abord, puis les deux règles sont déclarées.

  • delimiter: le point-virgule de l'export
  • demi_journees_non_justifiees>=4: la famille est convoquée
  • demi_journees_non_justifiees>10: le Dasen est informé
  • key: eleve_id, la décision porte l'élève
  1. 1
    Le compte est celui du logiciel

    lumnik lit le chiffre tel qu'il est exporté.

  2. 2
    Octobre

    Hugo Perrin avait 4: ces lignes précèdent les règles, rien n'est décidé.

Ce que prouve cette étape

Un seuil légal se déclare en une ligne.

Limites

  • lumnik ne somme pas les demi-journées: le compte doit venir de l'export.
  • Les élèves sont mineurs: noms synthétiques. Le scope du connecteur borne qui les lit.
  • Qui est informé à quatre varie selon la circulaire académique: la décision suit la page nationale.
  • Aucun message n'est envoyé: la décision arrive dans l'inbox de l'équipe.
  • Données synthétiques.
