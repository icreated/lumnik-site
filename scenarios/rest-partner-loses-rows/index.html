L'API du partenaire perd une page, le run ne ment pas.

Un partenaire publie 2 400 partenaires et leur nombre. Une nuit, une page de 100 disparaît, le nombre reste juste. lumnik compare ce qu'il a lu au total que la source déclare : le run échoue en nommant l'endpoint et les deux chiffres, au lieu de passer au vert.

Ce que prouve cette étape

Le prochain run complet remet la table à jour.

Limites

  • Le témoin ne vaut que si la source publie un vrai nombre de lignes.
  • Le contrôle tire en fin de pagination : les lignes déjà écrites restent.
  • Une source qui ne publie aucun total n'a pas de témoin.
  • API du partenaire simulée ; données synthétiques.
