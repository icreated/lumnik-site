lm source rest probe trouve la liste

La sonde lit /vets.json une fois et propose un fragment d'endpoint, à relire avant de l'appliquer.

  • la liste: $.vetList
  • aucun signe de pages: kind: none
  1. 1
    Une absence constatée

    none n'est proposé que si une liste est trouvée et qu'aucune clé ni en-tête ne parle de pages (#1650).

Spring PetClinic, d'avant Spring Boot

Le problème

L'app a été écrite avant les API modernes.

  • Elle rend de l'XML ou du JSON.
  • Toute la liste d'un coup, sans pages.

Ce qui n'est pas modifié

L'app reste telle quelle.

  • Un WAR sur Tomcat.
  • Spring MVC configuré en XML.

Le premier essai

L'adresse connue rend de l'XML.

  • Le hub lit du JSON.
  • Il refuse en le disant, au lieu de lire 0 ligne.

La sonde

lm source rest probe … --endpoint /vets.json

La sonde trouve la liste.

Elle propose kind: none: aucun signe de pages dans la réponse.

Ce qu'il a fallu écrire

pagination: { kind: none, response_path: $.vetList }

Une ligne.

  • 6 vétérinaires, une requête.
  • Un connecteur de 23 lignes.

La limite

Le hub ne lit pas l'XML.

  • Ici, la même app rend aussi du JSON.
  • Si la source pagine, il faut le déclarer.
