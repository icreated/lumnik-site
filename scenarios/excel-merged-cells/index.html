Un export Excel aux cellules fusionnées : chaque ligne avec sa région et son client.

Les ventes envoient chaque mois un rapport Excel : un groupe par client, la région et le client dans des cellules fusionnées, un sous-total sous chaque groupe. Enregistrée en CSV, une cellule fusionnée ne garde sa valeur que sur la première ligne du groupe ; les suivantes sont vides. Les ventes veulent chaque ligne avec sa région et son client.

Les lignes de vente, sans les sous-totaux

filter-where ne garde que les lignes datées : les 15 sous-totaux sont écartés et comptés. map-columns renomme les en-têtes, parse-date et parse-number lisent dates et montants. fill-down reporte la région et le client de la première ligne d'un groupe sur les suivantes.

  1. 1
    15 sous-totaux

    Écartés, comptés dans SKIPPED.

Ce que prouve cette étape

Un rapport mis en forme pour l'œil se lit comme une table.

manifests/10-sales.yaml
apiVersion: connectors.lumnik.io/v1kind: Connectormetadata:  name: scenario-excel-b  connector_type: csv-file  scopes: [sales-b]spec:  transport:    kind: local    path: /tmp/lumnik-scenario/excel-merged-cells/b/*.csv   # one Excel sales export per month  parser:    delimiter: ";"  after_process: none  mapping:    dataset:      - filter-where: { column: Date, regex: "\\d{2}/\\d{2}/\\d{4}" }   # the sale lines: a subtotal has no date    row:      - map-columns:          rename:            Région: region            Client: client            Date: sale_date            Pièce: piece            Article: article            Quantité: quantity            Montant HT: amount    cell:      - regex-extract: { column: sale_date, pattern: "^\\d{2}/(\\d{2})/\\d{4}$", groups: { 1: month } }      - parse-date: { column: sale_date, formats: ["dd/MM/yyyy"] }      - parse-number: { column: quantity, integer: true }      - parse-number: { column: amount }      - fill-down: { columns: [region, client] }   # a merged cell: written on its group's first row only

Limites

  • fill-down suit l'ordre du fichier : sort-by à côté est refusé.
  • Une ligne écartée par filter-where ne reporte rien : la première ligne d'un groupe ne doit pas être filtrée.
  • Fichiers synthétiques, clients fictifs.
