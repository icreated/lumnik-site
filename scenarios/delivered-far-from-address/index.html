Marqué livré à 2 km de l'adresse

Objectif Repérer chaque colis marqué livré loin de son adresse, ou sans position de scan, dès que le fichier du transporteur arrive.

«Colis marqué livré, jamais reçu» revient souvent devant le médiateur du e-commerce, et le vendeur doit une livraison conforme. Le fichier de preuve de livraison porte la position de l'adresse et celle du scan sur une même ligne. Aucun outil ne les compare: lumnik les compare.

  • la distance mesurée à l'entrée par le script de l'opérateur
  • au-delà de 200 m: une décision
  • sans position de scan: une autre

La distance mesurée à l'entrée

Le transporteur dépose ses preuves de livraison par SFTP. Le script de l'opérateur mesure la distance entre le scan et l'adresse.

  • kotlin: distance_m, en mètres (haversine)
  • distance_m>200: au-delà d'une entrée d'immeuble ou d'une erreur GPS
  • distance_issue=no scan position: sans position, aucune distance ne peut lever la ligne
  • le premier jour arrive avant les règles

Ce que prouve cette étape

Une distance se calcule une fois, à l'entrée.

manifests/scan-distance.kts
// Operator-provided: how far from the delivery address the driver's scan was taken, in metres (haversine, the Earth// as a sphere of 6,371,008.8 m). A point missing or out of range gives no distance, and distance_issue says why.@Suppress("UNCHECKED_CAST")val cells = bindings["cells"] as MutableMap<String, Any?>fun coord(name: String, limit: Double): Double? =    (cells[name] as String?)?.trim()?.replace(',', '.')?.toDoubleOrNull()?.takeIf { kotlin.math.abs(it) <= limit }val lat1 = coord("address_lat", 90.0); val lon1 = coord("address_lon", 180.0)val lat2 = coord("scan_lat", 90.0); val lon2 = coord("scan_lon", 180.0)if (lat1 == null || lon1 == null || lat2 == null || lon2 == null) {    cells["distance_m"] = null    cells["distance_issue"] = if (lat2 == null || lon2 == null) "no scan position" else "no address position"} else {    val r = 6_371_008.8    val dLat = Math.toRadians(lat2 - lat1); val dLon = Math.toRadians(lon2 - lon1)    val a = Math.pow(Math.sin(dLat / 2), 2.0) + Math.cos(Math.toRadians(lat1)) * Math.cos(Math.toRadians(lat2)) * Math.pow(Math.sin(dLon / 2), 2.0)    cells["distance_m"] = Math.round(2 * r * Math.asin(Math.sqrt(a))).toString()    cells["distance_issue"] = null}

Limites

  • Aucun transformer ne mesure une distance: il faut le script de l'opérateur, installé dans le dossier de hooks.
  • 200 m est un choix: un grand site, un casier ou un point relais demande son propre seuil.
  • Un scan lointain n'est pas une fraude: la décision demande la preuve.
  • Le rapport du médiateur ne chiffre pas ces cas: cette preuve est plus faible que d'autres.
  • Six livraisons synthétiques à Lyon.
