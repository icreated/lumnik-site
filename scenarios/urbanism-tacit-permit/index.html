Un permis bientôt accordé par le silence de la mairie

Objectif Être prévenu sept jours avant qu'une demande d'urbanisme non tranchée devienne une décision tacite, selon son type et son délai légal.

Une mairie instruit les demandes d'urbanisme. Sans décision notifiée dans le délai, le silence vaut non-opposition ou permis tacite. Une mairie qui perd un dossier de vue a décidé sans le vouloir: l'alerte ne vaut que si elle arrive avant.

  • le délai en mois, calculé à l'entrée par le script de l'opérateur
  • l'alerte sept jours avant l'échéance
  • l'exception ABF écrite une fois

Le délai légal calculé à l'entrée

Le registre des demandes arrive par SFTP. Le script de l'opérateur calcule l'échéance et l'alerte.

  • DP: 1 mois, PCMI et PD: 2 mois, PC et PA: 3 mois (R*423-23)
  • warn_on: sept jours avant l'échéance
  • avis ABF: le silence vaut rejet (R*424-3), pas d'alerte
  • due.column: warn_on, en état EN_INSTRUCTION
  1. 1
    Des mois, pas des jours

    Le script ajoute des mois, comme le code les compte.

  2. 2
    L'exception

    tacit_issue dit pourquoi un dossier n'a pas d'alerte.

Ce que prouve cette étape

Un délai légal en mois se déclare une fois.

manifests/tacit-deadline.kts
// Operator-provided: when a town hall's silence on a planning application becomes a tacit decision, and when to warn.// Code de l'urbanisme R*423-23: 1 month for a prior declaration (DP), 2 for a house (PCMI) or a demolition (PD),// 3 for any other building permit (PC) or a development permit (PA), from the day the file is complete.// R*424-1: silence then counts as non-opposition or a tacit permit. R*424-3: with the ABF's opinion, silence is a// refusal — no tacit decision, so no warning. The warning falls 7 days before the deadline.@Suppress("UNCHECKED_CAST")val cells = bindings["cells"] as MutableMap<String, Any?>val months = when ((cells["type"] as String?)?.trim()) {    "DP" -> 1L    "PCMI", "PD" -> 2L    "PC", "PA" -> 3L    else -> null}val complete = (cells["complete_on"] as String?)?.trim()val abf = (cells["abf"] as String?)?.trim() == "oui"val deadline = if (months == null || complete.isNullOrEmpty()) null else java.time.LocalDate.parse(complete).plusMonths(months)cells["deadline_on"] = deadline?.toString()cells["warn_on"] = if (deadline == null || abf) null else deadline.minusDays(7).toString()cells["tacit_issue"] = when {    months == null -> "unknown type"    complete.isNullOrEmpty() -> "file not complete"    abf -> "ABF opinion: silence is a refusal (R*424-3)"    else -> null}

Deux dossiers à trancher avant le silence

Au balayage suivant, chaque dossier en instruction à moins de sept jours de son échéance donne une décision.

  • DP-2026-041, une clôture: 1 mois
  • PC-2026-008, un hangar: 3 mois
  • la maison individuelle, loin de son échéance: rien
  • le dossier accordé, et celui avec avis ABF: rien
  1. 1
    Vérifié à part

    data/check_deadlines.py calcule les mêmes alertes, avec son propre code.

  2. 2
    L'échéance dans la phrase

    La décision cite le jour où le silence deviendra une décision.

Limites

  • Les délais majorés (commission, monument, autre autorisation) ne sont pas lus: le script prend les délais de droit commun.
  • Une demande de pièces qui relance le délai n'est pas lue: le registre donne le jour du dossier complet.
  • Les centaines d'autres démarches «silence vaut accord» ne sont pas couvertes: ce scénario prend l'urbanisme.
  • Aucune décision n'est prise: lumnik prévient l'équipe, le maire décide et notifie.
  • Cinq dossiers synthétiques, datés depuis le jour du rejeu.
