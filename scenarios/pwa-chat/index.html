Une question, une requête en lecture seule

run/run.sh pose « Combien d'articles appartiennent à la catégorie Pompes ? » par lm ask. Le runner échoue si aucun SQL n'est exécuté.

  1. 1
    Lecture seule

    La requête passe par la source readonly et ses gardes.

  2. 2
    Vérifiable

    Le SQL est montré avec la réponse.

Ce que prouve cette étape

La réponse vient d'une requête exécutée sur l'entité, pas du modèle seul.

Limites

  • Requêtes analytiques sur l'entité ; pas de recherche sémantique dans du texte libre.
  • Dépend d'un modèle joignable ; le rejeu échoue sans lui.
  • Données synthétiques.
