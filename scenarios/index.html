Scénarios rejoués

Chaque scénario a été rejoué sur un hub lumnik : les manifestes, les commandes et les résultats affichés sont ceux du rejeu. Les données sont synthétiques.

Achats

  • Pro

    La question à laquelle Ask refuse de répondre : une marge sans coût, un « meilleur » sans critère.

    Un directeur achats pose ses questions à un an de commandes fournisseurs, avec ses mots. Trois questions reçoivent leur chiffre, avec le SQL qui l'a produit. Trois autres n'ont pas de réponse dans ces données : une marge sans prix de revient, un meilleur fournisseur sans critère, des retards sans date de livraison. Ask les refuse au lieu d'inventer un chiffre qu'on répéterait en réunion.
