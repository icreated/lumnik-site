Lecture seule. Les connecteurs lisent. Aucun chemin n'écrit vers vos logiciels.

L'isolation vit dans la base. PostgreSQL cloisonne ligne par ligne (Row-Level Security), par organisation.

Le SQL généré ne peut que lire. Avec Pro, la requête de l'IA s'exécute sous un rôle sans droit d'écriture, quoi que produise le modèle.

Le journal d'audit ne se réécrit pas. Le rôle applicatif n'a ni UPDATE ni DELETE dessus. Une purge de rétention le taille au-delà de 365 jours par défaut, réglable.

Chez vous. Le hub tourne sur vos serveurs. Avec Pro, le modèle d'IA peut tourner dans vos murs.

Réversible. Des tables PostgreSQL ordinaires et un pg_dump standard. Aucune copie à réclamer chez un éditeur.
