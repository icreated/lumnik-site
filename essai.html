Gratuit · Apache-2.0

Essayez lumnik Open, chez vous.

Une commande installe le hub, sa base et son serveur de connexion. Ensuite, chargez un premier export.

1

Préparez la machine

Docker et Docker Compose, avec curl, python3, openssl et awk. Linux ou macOS. Sous Windows, passez par WSL2.

Les prérequis · Sous Windows

2

Lancez le hub

Le script crée les secrets de l'installation, puis démarre le hub.

 installer lumnik Open
$ git clone https://github.com/icreated/lumnik-open.git && cd lumnik-open
$ ./deploy/selfhost/up.sh --build
…
==> hub is healthy
  Hub:       http://localhost:8080   (health: /q/health)
  Keycloak:  http://localhost:8180/realms/lumnik

Le déploiement en détail

3

Installez lm

lm pilote le hub depuis le terminal. Prenez l'archive de votre système sur la page des versions.

Chargez un premier export

Le démarrage rapide charge un fichier CSV et affiche ses lignes. Puis le WOW : deux logiciels deviennent un seul client, une vue, une décision.
