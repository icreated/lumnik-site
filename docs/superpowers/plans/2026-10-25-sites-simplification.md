# Sites simplification Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** lumnik.fr and lumnik.io become short sites that lead a visitor from "why" to a replayed
scenario to installing lumnik Open; the scenario catalogue is grouped by problem and every
scenario page ends on "try it".

**Architecture:** Three repositories. The two sites stay zero-build static HTML, each with its
own structural test (`tests/site_structure_test.py`, stdlib only) rewritten first. The catalogue
and the scenario pages are generated by `lumnik-scenario/tools/scenario-site/publish_site.py`;
the family table and the closing block live there, the site only passes its copy and links.

**Tech Stack:** HTML/CSS (no framework), Python 3 stdlib `unittest`, `node --test` (dossier only).

**Spec:** `docs/superpowers/specs/2026-10-25-sites-simplification-design.md`

## Global Constraints

- One idea per sentence; a list rather than a sentence of commas; the mechanism, never the virtue.
- Forbidden wordings (FR, every page and scenario page): temps réel · zéro risque · Personne ne ·
  honnête · proxy · sources citées · sourcée · avec ses sources · en français · fuite de données ·
  pour toujours · sans risque · lumnik Console · console-preuve · Demander une démonstration ·
  Demander un pilote · bac à sable · Demander mes accès.
- Forbidden wordings (EN): honest · real-time · zero-risk · forever · cites its sources ·
  EU cloud · walkthrough · Book a · exists today · cannot be erased · quote_unmoved.
- French typography: U+202F (`&#8239;`) before `;` `!` `?`, U+00A0 (`&nbsp;`) before `:` `%`.
- Only real outputs: `donnees/p1008.json`, the `up.sh` lines of docs/deploy.md, the scenarios'
  titles from `scenarios/index.json`.
- Never push to a site's `main` (a push deploys). One branch `site/simplify` per site, one PR each.
- `scenarios/` is never edited by hand in a site.
- Run before every site commit: `python3 -m unittest tests/site_structure_test.py`
  (FR also: `node --test 'tests/js/*.test.mjs'`).

## Review Focus

1. **A phone at 390 px**: the long `git clone …` line and the five steps must scroll or wrap
   inside their box, never the page — checked in Chrome at 390 px (Task 6).
2. **The pill on its own page** (`essai.html`, `try.html` current): the `aria-current` rule
   paints yellow on yellow unless the pill rule follows it — FR gets the EN rule and its test (Task 2).
3. **An old bookmark with a fragment** (`produit.html#sens`, `pour-qui.html#integrateurs`):
   the relay keeps the fragment and the home answers it — RelayTest (Tasks 2, 4).
4. **A scenario retitled or retired later**: a home card would lie or 404 — the cards are
   pinned to `scenarios/index.json` titles and their links must resolve (Tasks 2, 4).
5. **A new scenario with no family**: the publisher refuses it by name; a family with no
   offered scenario renders no empty section (Task 5).
