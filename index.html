Tous les scénarios

Comment

Cinq gestes. Aucune écriture dans vos logiciels.

Lire

Les connecteurs lisent vos fichiers, vos bases et vos API. Rien n'est écrit dans vos logiciels.

Réparer

Dates, accents, montants, formats anciens d'un export : la correction se déclare à l'entrée. Une ligne illisible est mise de côté, avec sa raison.

Rassembler

Plusieurs sources deviennent une fiche. Leurs désaccords restent visibles.

Surveiller

Chaque lecture est datée. Ce qui dort au-delà du seuil déclaré arrive dans une boîte de décisions.

Servir

Une app par métier sur le téléphone, une API, du SQL, des webhooks. Avec Pro, des questions en langage naturel.

Rien ne se perd sans être compté. À chaque lecture, les lignes lues égalent les lignes écrites plus les lignes écartées.

Essayer

lumnik Open s'installe en une commande.

Gratuit et open source, sous licence Apache-2.0. Une machine avec Docker suffit.

 installer lumnik Open
$ git clone https://github.com/icreated/lumnik-open.git && cd lumnik-open
$ ./deploy/selfhost/up.sh --build

Confiance

Ce que votre DSI peut vérifier.

  • Lecture seule. lumnik n'écrit jamais dans vos systèmes.
  • Isolation par la base. PostgreSQL cloisonne chaque ligne par organisation.
  • Chez vous. Sur vos serveurs. L'IA de Pro peut tourner dans vos murs.
  • Réversible. Des tables PostgreSQL ordinaires, un pg_dump standard.
